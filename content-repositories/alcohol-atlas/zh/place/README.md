# 地点

- [萨沃伊美式酒吧](american-bar-savoy.md) — 伦敦萨沃伊酒店内的经典美式酒吧，1893 年随酒店开业，以《萨沃伊鸡尾酒书》和经典调酒传统闻名。
- [中央咖啡馆](cafe-central.md) — 维也纳历史悠久的文学咖啡馆，1876 年开业，以咖啡、蛋糕和知识分子顾客闻名。
- [花神咖啡馆](cafe-de-flore.md) — 巴黎圣日耳曼德佩的文学咖啡馆，19 世纪末开业，以知识分子顾客和经典巴黎咖啡馆氛围闻名。
- [花神咖啡馆（威尼斯）](caffe-florian.md) — 威尼斯圣马可广场的历史咖啡馆，1720 年开业，是欧洲持续经营时间最长的咖啡馆之一。
- [鹰与孩童酒馆](eagle-and-child.md) — 牛津圣吉尔斯街的历史酒馆，以“Inklings”文学小组（托尔金、C.S.刘易斯等）的聚会地闻名。
- [小佛罗里达酒馆](el-floridita.md) — 哈瓦那老城的传奇酒吧，1817 年创立，以海明威、冷冻代基里和海鲜吧闻名。
- [古井酒文化博物馆](gujing-wine-culture-museum.md) — 位于安徽省亳州市谯城区古井镇古井酒厂对面的酒文化博物馆，1994 年建成、1996 年开放。开放时间与票务需另行核实。
- [哈里酒吧（威尼斯）](harrys-bar-venice.md) — 威尼斯圣马可广场附近的传奇酒吧，1931 年由朱塞佩·奇普里亚尼创立，以贝里尼和生牛肉薄片闻名。
- [皇家啤酒屋](hofbrauhaus.md) — 慕尼黑历史悠久的啤酒馆，1589 年由巴伐利亚公爵创立，以啤酒大厅和巴伐利亚菜闻名。
- [半途小酒馆](la-bodeguita-del-medio.md) — 哈瓦那老城的著名小酒馆，1942 年开业，以莫吉托和文人顾客的墙面签名闻名。
- [双叟咖啡馆](les-deux-magots.md) — 巴黎圣日耳曼德佩的文学咖啡馆，1885 年开业，曾与海明威、萨特和波伏娃等名字联系在一起。
- [麦克索利老麦酒馆](mcsorleys-old-ale-house.md) — 纽约东村的历史酒馆，1854 年开业，以只供应淡色和深色艾尔、历史陈设闻名。
- [莱佛士长廊酒吧](raffles-long-bar.md) — 新加坡莱佛士酒店的历史酒吧，以新加坡司令和花生壳传统闻名。
- [施伦克拉烟熏啤酒馆](schlenkerla.md) — 德国班贝格的 historic 烟熏啤酒酒馆，以 Rauchbier 和传统法兰肯菜闻名。
- [弗勒克啤酒屋](u-fleku.md) — 布拉格历史悠久的啤酒馆和微型啤酒厂，创立于 1499 年，以自酿黑啤和捷克菜闻名。
- [白马酒馆](white-horse-tavern.md) — 纽约格林威治村的历史酒馆，1880 年开业，因诗人迪伦·托马斯等文人顾客闻名。
- [柴郡奶酪酒馆](ye-olde-cheshire-cheese.md) — 伦敦舰队街的历史酒馆，现建筑 1667 年重建，以木结构内饰和传统英式菜闻名。
