# 酒款

[返回中文目录](../README.md)

- [奔富葛兰许](australia-penfolds-grange.md) — 澳大利亚奔富酒庄旗舰酒，由马克斯·舒伯特于 1951 年首创，以设拉子为主的跨产区混酿。
- [二锅头](beijing-erguotou.md) — 北京传统白酒工艺与产品类别，因取第二锅冷却流出的酒液而得名，风格清香、直接。
- [百加得白朗姆](cuba-bacardi-carta-blanca.md) — 以糖蜜为原料的白朗姆酒，经活性炭过滤，常见酒精度 40% vol，适合调制莫吉托和代基里。
- [哈瓦那俱乐部7年](cuba-havana-club-7-year-old.md) — 古巴朗姆酒品牌，以糖蜜蒸馏的朗姆酒调配并陈年，常见酒精度 40% vol。
- [皮尔森之源](czech-pilsnerurquell.md) — 捷克皮尔森市的淡色拉格啤酒，1842 年首次酿造，酒精度约 4.4% vol。
- [查特酒](france-chartreuse.md) — 法国加尔都西会修士在 Voiron 生产的草本利口酒，绿查特酒精度 55% vol，黄查特 40% vol。
- [拉菲古堡红葡萄酒](france-chateaulafiterothschild.md) — 法国波尔多波亚克一级庄，以赤霞珠为主的混酿，酒体紧致、陈年潜力长。
- [唐·培里侬香槟](france-domperignon.md) — 酩悦香槟旗下的年份香槟品牌，只在特定年份生产，常见酒精度 12.5% vol。
- [轩尼诗XO](france-hennessyxo.md) — 法国干邑白兰地，由轩尼诗调配百余种生命之水，常见酒精度 40% vol。
- [罗曼尼·康帝](france-romaneeconti.md) — 法国勃艮第沃恩-罗曼尼村的特级园，由罗曼尼·康帝酒庄拥有，全部种植黑皮诺。
- [茅台酒](guizhou-moutai.md) — 产自贵州仁怀茅台镇的酱香型白酒代表，以高粱和小麦高温大曲酿造，常见酒精度 53% vol。
- [酒鬼酒](hunan-jiugui.md) — 产自湖南吉首的馥郁香型白酒，融合浓香、清香和酱香工艺特点，常见酒精度 52% vol。
- [健力士世涛啤酒](ireland-guinnessdraughtstout.md) — 爱尔兰都柏林圣詹姆斯门啤酒厂生产的干世涛，代表产品酒精度约 4.2% vol。
- [尊美醇爱尔兰威士忌](ireland-jamesonirishwhiskey.md) — 爱尔兰调和威士忌品牌，由 Midleton 蒸馏厂生产，三次蒸馏，常见酒精度 40% vol。
- [金巴利](italy-campari.md) — 意大利苦味开胃酒，1860 年创立于米兰，酒精度通常 20.5%–25% vol，苦甜平衡。
- [西施佳雅](italy-sassicaia.md) — 意大利托斯卡纳保格利产区的葡萄酒，以赤霞珠和品丽珠为主，是“超级托斯卡纳”代表之一。
- [山崎单一麦芽威士忌](japan-yamazaki.md) — 日本三得利在京都山崎设立的麦芽威士忌蒸馏厂，1923 年投产，常见酒精度 43% vol。
- [洋河酒](jiangsu-yanghe.md) — 产自江苏宿迁的浓香型白酒品牌，以“绵柔”风格和蓝色经典系列知名，酒精度覆盖多个度数。
- [麦卡伦18年雪莉桶](scotland-themacallan.md) — 苏格兰斯佩塞单一麦芽威士忌，以雪莉调味橡木桶陈年风格著称，常见酒精度 43% vol。
- [西凤酒](shaanxi-xifengjiu.md) — 产自陕西凤翔的凤香型白酒代表，以高粱、大麦、小麦和豌豆制曲，常见酒精度 55% vol。
- [张裕葡萄酒](shandong-changyu.md) — 山东烟台葡萄酒品牌，张裕公司创建于 1892 年，产品覆盖干红、干白和白兰地。
- [青岛啤酒](shandong-tsingtao.md) — 产自山东青岛的拉格啤酒品牌，1903 年创办，主力产品酒精度约 4% vol。
- [汾酒](shanxi-fenjiu.md) — 产自山西汾阳杏花村的清香型白酒代表，以高粱、大麦和豌豆制曲，常见酒精度 53% vol。
- [剑南春](sichuan-jiannanchun.md) — 产自四川绵竹的浓香型白酒，以五粮为原料、泥窖固态发酵，常见酒精度 52% vol。
- [郎酒](sichuan-langjiu.md) — 产自四川古蔺赤水河畔的白酒品牌，兼有酱香与浓香产品，青花郎等酱香产品较为知名。
- [泸州老窖](sichuan-luzhoulaojiao.md) — 产自四川泸州的浓香型白酒代表，以老窖池续糟发酵为特色，常见产品酒精度 52% vol。
- [五粮液](sichuan-wuliangye.md) — 产自四川宜宾的浓香型白酒，以高粱、大米、糯米、小麦、玉米五种粮食为原料，常见酒精度 52% vol。
- [绝对伏特加](sweden-absolutvodka.md) — 瑞典伏特加品牌，以冬小麦为原料、连续蒸馏，常见酒精度 40% vol。
- [必富达伦敦干金酒](uk-beefeater.md) — 伦敦干金酒品牌，1863 年创立，以杜松子和柑橘等植物原料蒸馏，常见酒精度 40% vol。
- [杰克丹尼老7号](usa-jackdaniels.md) — 美国田纳西威士忌，采用林肯县木炭过滤工艺，常见酒精度 40% vol。
- [古越龙山花雕酒](zhejiang-guyuelongshan.md) — 浙江绍兴黄酒品牌，以糯米、麦曲和鉴湖水酿造，花雕、加饭等产品常见酒精度 15%–18% vol。
