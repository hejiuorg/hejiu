# 酒类风格

[返回中文目录](../README.md)

- [开胃酒](aperitif.md) — 餐前饮用、以苦味或干型风味为主的一类酒饮；它是按场景划分的类别，而不是按原料划分的单一酒种。
- [保健酒](baijiu-medicinal.md) — 以蒸馏酒或黄酒为基酒、加入药食同源原料制成的配制酒；它是食品类别，不是药品，功能声称受严格限制。
- [白酒](baijiu.md) — 以粮谷为主要原料、经糖化发酵与蒸馏而成的中国传统蒸馏酒。香型是常见分类维度，但不是唯一维度。
- [啤酒](beer.md) — 以谷物糖化、发酵并通常加入啤酒花酿成的低到中等酒精度饮品，按发酵方式、原料和地域形成庞大风格谱系。
- [白兰地](brandy.md) — 以葡萄酒或其他水果酒蒸馏而成的烈酒；干邑、雅文邑、卡尔瓦多斯与果渣白兰地各有法定工艺与产区。
- [果酒](fruit-wine.md) — 以水果汁或水果浸提液发酵而成的低到中等酒精度饮品；与水果利口酒、水果白兰地属于不同类别。
- [金酒](gin.md) — 以杜松子为核心风味的蒸馏烈酒，按蒸馏方式和添加物分为伦敦干金、蒸馏金酒与复合金酒等类别。
- [利口酒](liqueur.md) — 以烈酒为基底、加入糖和风味原料制成的甜味酒；按风味可分为水果、草本、坚果、奶油和咖啡等家族。
- [其他酒类（旧分类容器）（draft）](other.md) — 旧站“其他”分类的映射容器，仅用于保持历史子分类映射完整；不发布，不作为新的酒类分类。
- [朗姆酒](rum.md) — 以甘蔗汁或糖蜜发酵蒸馏而成的烈酒，按原料、蒸馏与陈年形成白朗姆、金朗姆、深色朗姆和农业朗姆等类别。
- [清酒](sake.md) — 以米、水、米曲和酵母酿成的日本传统酒类，按精米步合、是否添加酿造酒精与处理方法形成不同类别。
- [烧酒](soju.md) — 朝鲜半岛的传统蒸馏酒，现代大众烧酒多为稀释型；与日本烧酎在原料、法规和风味上并不相同。
- [浓香型白酒](strong-aroma-baijiu.md) — 以泥窖固态发酵、续糟配料和混蒸混烧等工艺为特征的浓香型白酒，是白酒风格分类中的一类。
- [龙舌兰酒](tequila.md) — 以蓝色韦伯龙舌兰为原料、在墨西哥法定产区生产的蒸馏酒；100% 龙舌兰与混合型、不同陈年等级差异明显。
- [伏特加](vodka.md) — 以谷物、马铃薯、糖蜜等为原料，经发酵蒸馏和过滤得到的中性烈酒；风味差异比“无色无味”的刻板印象更丰富。
- [威士忌](whisky.md) — 以谷物为原料、经发酵蒸馏并在橡木桶中陈年的烈酒；苏格兰、爱尔兰、美国、日本等地各有法规与传统。
- [葡萄酒](wine.md) — 以葡萄汁发酵而成的酒精饮料，按颜色、甜度、气泡与产地法规形成不同类别；风土与年份只是部分变量。
- [黄酒](yellow-wine.md) — 中国传统的谷物发酵酒，以稻米为主料、麦曲或酒药糖化发酵而成；绍兴酒是其中最知名的地理标志产品。
