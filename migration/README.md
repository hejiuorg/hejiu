## 判型与字段规则

- 保留的酒款按香型/工艺连接到 `drink-style`；停用的酒款不再作为公开页面。
- 保留的 16 个地点为可独立成页的历史酒吧/咖啡馆；地址、城市与国家保留，坐标 `null`，营业状态 `unknown`，不推断营业。
- 57 个诗词摘句全部停用；不再保留摘句页，未来诗词以公版原文校勘后的专题形式独立撰写。
- 旧 `nameEn` 只作为别名，不生成英文正文。
- 旧标签与子分类不直接进入受控 `tags`；原值保留在映射文档中。

## 旧路由覆盖

`legacy-routes.json` 覆盖：

- 602 条详情记录（其中 48 条保留目标，554 条停用）；
- 7 个功能入口；
- 17 个分类、93 个子分类；
- 32 个省份的两种旧参数形式、313 个中国城市分支；
- 43 个国家、6 个洲、43 个酒馆国家、97 个酒馆城市；
- 397 个旧标签；
- 旧 `#?` hash 形式与查询形式等价。

停用详情没有目标，旧 URL 直接进入 `/404.html`，不跳到无关页面。分类/子分类/标签和地区分支仍保留。

## 不做什么

- 不把停用记录重新发布成薄页。
- 不把旧宣传语、历史断言或人物关系当作已核实事实。
- 不把 `nameEn` 当成英文正文。
- 不伪造营业状态、坐标、路线、活动或图片许可。
- 不删除台账行；停用行保留原因与备份。
